# Library system in Java with graphical interface

This repository contains a Java-based library system with a graphical user interface (GUI). It allows users to manage books and magazines within a library providing functionalities to add, search and display library resources.

## Features

-   **Graphical User Interface:** Provides an intuitive interface for managing library resources.
-   **Book Management:** Allows adding, searching and displaying books in the library.
-   **Magazine Management:** Supports similar functionalities for managing magazines.
-   **Author Information:** Includes features to manage and display author information.

## Installation

1.  Clone the repository:

    ```bash
    git clone https://github.com/panoschron97/Library_system_in_java_with_graphical_interface.git
    ```

2.  Navigate to the project directory:

    ```bash
    cd Library_system_in_java_with_graphical_interface
    ```

3.  Compile the Java source files.  Ensure you have the Java Development Kit (JDK) installed.  From the `Librarysystemm/src` directory:
    ```bash
    javac *.java
    ```

4.  Move the compiled `.class` files to the `Librarysystemm/bin` directory

## Usage

1.  Navigate to the `Librarysystemm/bin` directory:

    ```bash
    cd Librarysystemm/bin
    ```

2.  Run the `Main` class to start the application:

    ```bash
    java Main
    ```

    This command will launch the library system's GUI allowing you to interact with the library's functionalities.

## Dependencies

-   **Java Development Kit (JDK):** Required to compile and run the Java application.
